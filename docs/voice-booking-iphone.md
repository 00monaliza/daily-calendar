# Голосовая бронь с iPhone (Action Button + Shortcut)

Поток: Action Button → команда «Бронь» → диктовка → Edge Function `voice-booking`
(разбор фразы через Claude + проверка занятости) → черновик в `voice_booking_drafts`
→ в приложении открывается форма брони с заполненными полями → пользователь
проверяет и нажимает «Сохранить». Сама функция бронь **не создаёт**.

## 1. Развёртывание (один раз)

1. Применить миграцию `supabase/migrations/007_voice_booking.sql`
   (SQL Editor в Supabase или `supabase db push`). Она добавляет
   `properties.voice_aliases`, таблицы `voice_tokens` и `voice_booking_drafts`
   и заполняет короткие голосовые названия (только там, где они ещё пустые):
   Алматау → 89, Инжу Арена 12 → 12, Инжу Арена 24 → 24, Весна 3 → 49, 1509, 2006.
   Числовое название говорите **первым словом**: «24, Айгерим, с 12 по 15…».
   Число в середине фразы считается датой или суммой, а не квартирой.
   Проверить: `select name, voice_aliases from properties;` — если у какой-то
   квартиры массив пустой, название в базе отличается; задайте псевдонимы на
   странице «Квартиры» → «Голосовые названия».
2. Секреты функции:
   ```bash
   supabase secrets set ANTHROPIC_API_KEY=sk-ant-... APP_URL=https://<домен-приложения>
   # необязательно: другая модель (по умолчанию claude-haiku-5-5)
   # supabase secrets set VOICE_BOOKING_MODEL=claude-sonnet-5-5
   # необязательно: лимит вызовов на владельца за 24 часа (по умолчанию 30)
   # supabase secrets set VOICE_BOOKING_DAILY_LIMIT=50
   ```
   Без `APP_URL` команда не сможет открыть приложение (`open_url` будет `null`),
   но черновик всё равно появится баннером в календаре.
3. Деплой — обязательно с `--no-verify-jwt`: у Shortcut нет Supabase JWT,
   функция сама проверяет `x-voice-token`:
   ```bash
   supabase functions deploy voice-booking --no-verify-jwt
   ```

## 2. Настройка iPhone

Приложение → «Настройки» → «Голосовая бронь (iPhone)» → «Создать токен».
Там же адрес функции и пошаговая инструкция для приложения «Команды»:

1. «Диктовать текст» (русский, «После паузы»).
2. «Получить содержимое URL»: POST, заголовок `x-voice-token`, JSON-тело `text` = продиктованный текст.
3. «Получить значение словаря» `summary` → «Показать предупреждение» (и/или «Произнести текст»).
4. «Получить значение словаря» `open_url` → «Открыть URL-адреса».
5. Настройки iPhone → «Кнопка действия» → «Команда» → «Бронь».
   Без Action Button: Универсальный доступ → Касание → «Касание задней панели».

Ограничение iOS: «Открыть URL» открывает Safari, а не PWA с экрана «Домой»
(у них раздельные хранилища, поэтому в Safari нужно войти один раз). Если
удобнее PWA, пропустите шаг 4 — черновик ждёт баннером в календаре.

## Ответ функции

```json
{
  "draft_id": "uuid",
  "open_url": "https://<app>/?voice_draft=uuid",
  "summary": "🏠 Инжу Арена 12\n📅 12 ноября – 15 ноября (3 ночи)\n👤 Айгерим\n💰 45 000 ₸, внесено 10 000 ₸\n✅ Свободно"
}
```

## Автосохранение

Бронь сохраняется сразу, без формы, если **одновременно**: распознаны квартира,
даты, имя и сумма; ни одно из этих полей не помечено как сомнительное; даты
свободны. Команда покажет «✅ Бронь сохранена» и откроет календарь. Иначе —
черновик на подтверждение (баннер в календаре), как раньше. Выключить:
`supabase secrets set VOICE_BOOKING_AUTOSAVE=false`.

## Расходы и защита ключа Anthropic

- Функцию можно вызвать **только по токену команды**: вход по JWT убран, так
  что сотрудники и другие пользователи приложения не тратят ключ.
- Не больше `VOICE_BOOKING_DAILY_LIMIT` вызовов (по умолчанию 30) на владельца
  за 24 часа; сверх лимита ответ 429 с понятным `summary`, Claude не вызывается.
- Одна фраза на Haiku 5.5 стоит порядка $0,0003. Дополнительно поставьте лимит
  расходов в console.anthropic.com → Settings → Limits — он ограничивает траты
  даже при утечке ключа.
- В ответе нет разобранных полей: черновик с телефоном из истории гостя
  читается приложением под RLS, поэтому утёкший токен не раскрывает номера гостей.

Логика пересечений (`supabase/functions/_shared/bookingAvailability.ts`) общая
для функции и приложения: выезд и заезд в один день не считаются пересечением.
Форма брони проверяет занятость вживую и для обычных броней, и при пересечении
предлагает ближайшие свободные даты той же длины и свободные на эти даты квартиры.
